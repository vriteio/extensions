# Andesine Pages

Hosts an Andesine collection as a documentation site at `<subdomain>.andesine.page`, or on your
own domain. The “Site” panel of a collection sets up the site, its configuration, and its
builds. The extension also adds element views for the content components of Pages sites
(`Callout`, `Card`, `Tabs`, `Steps`, and others), so their content stays editable in the editor.

For setup, see [Hosted sites](https://andesine.app/docs/publishing/hosted-sites/).
